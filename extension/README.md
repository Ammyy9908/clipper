# clipPlay - Chrome Extension

> One-click YouTube Video & MP3 Downloader for Google Chrome (Manifest V3)

## How It Works

1. Injects a native, sleek **Download** button on YouTube video pages (and in YouTube Shorts) right next to Like and Share.
2. Clicking **Download** opens `https://www.clipplay.video/?url=...` in a new tab.
3. The clipPlay web app automatically extracts the video, resolves formats (1080p, 720p, 4K, 320kbps MP3), and lets you save directly to your device with full support for video splitting, live progress bars, and Google login benefits (20 downloads/day).

---

## How to Install in Chrome

1. Open **Google Chrome**.
2. Go to: `chrome://extensions/`
3. Toggle **Developer mode** ON in the top right corner.
4. Click **Load unpacked** (or click the 🔄 **Reload icon** if already added).
5. Select this directory:
